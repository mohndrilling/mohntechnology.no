# Images folder

Replace the placeholder SVGs here with your real images.

- **hero/** – Main hero image (e.g. `hero.jpg`). Update `hero.image` in `src/content/pages/home.md`.
- **features/** – Optional images for each feature card (`feature1`, `feature2`, `feature3`).
- **product/slideshow/** – Images for the product section carousel. Configure `productSlideshow` in `home.no.md` / `home.en.md`.

See **CONTENT.md** in the project root for full instructions.
