# Produktslideshow

Legg bilder til Salmoscan-produktseksjonen her (JPG, PNG eller WebP anbefales).

1. Kopier filene hit, f.eks. `slide-01.jpg`, `slide-02.jpg`, …
2. Oppdater `productSlideshow` i `src/content/pages/home.no.md` og `home.en.md` med stier som `/images/product/slideshow/slide-01.jpg`
3. Valgfritt: sett `alt:` per slide for universell utforming

Plassholder-SVG-ene (`slide-01.svg` …) kan slettes når du har ekte bilder.
