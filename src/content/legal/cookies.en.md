## 2. What are cookies and similar technologies?

**Cookies** are small text files stored by the browser. **Similar technologies** include local storage, session storage, and pixels. Norwegian / EU rules (ePrivacy / Communications Act practice + GDPR) require clear information, and consent where storage or access is not strictly necessary for a service you request.

## 3. What this site uses today

### 3.1 First-party HTTP cookies

At the time of this draft, **Mohn Technology does not set its own HTTP cookies** on the company site for analytics, advertising, or preference storage.

### 3.2 Local storage (necessary / functional)

| Name | Type | Purpose | Duration |
|------|------|---------|----------|
| `theme` | localStorage | Remembers light or dark appearance after you use the theme toggle | Until you clear site data or change the setting |

This is stored only on your device. It is not a cookie and is not required for reading the site (a default theme still applies).

### 3.3 Strictly necessary server processing

Hosting may create short-lived **server logs** (IP, user agent, URL). These are not browser cookies. See the privacy policy.

### 3.4 Third-party resources (fonts)

Pages load fonts from Google Fonts. Your browser may request files from Google’s domains. That can involve processing of technical data by Google. We do not load analytics or ad scripts on this site in the current build.

**Compliance note for go-live:** either self-host fonts, or treat third-party font loading as a technology that needs documented legal basis / consent design consistent with your counsel’s advice.

## 5. How to control storage

You can:

- clear site data / localStorage for this domain in browser settings
- use browser controls that block third-party content
- browse without using the theme toggle (no `theme` value is written until you change theme)

If we later introduce a consent banner, non-essential cookies will not be set before consent (except where the law allows necessary storage).
