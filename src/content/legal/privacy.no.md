## 2. Virkeområde

Denne erklæringen beskriver behandling av personopplysninger når du bruker Mohn Technologys firmnettsted (inkl. språkversjoner) og tilhørende kontaktkanaler beskrevet her. Produktportaler (for eksempel Salmoscan kundeportal) og kundekontrakter kan ha egne vilkår.

## 3. Hva vi behandler og hvorfor

### 3.1 Kontaktskjema og e-post

Når du bruker kontaktskjemaet eller skriver til oss på e-post, behandler vi:

- navn
- e-postadresse
- meldingsinnhold
- valgfri interesse / tema (for eksempel produktlinje)
- tekniske metadata som kan fremgå av e-posthoder eller serverlogger (tidspunkt, IP-adresse)

**Formål:** å besvare henvendelsen og rute den internt.  
**Behandlingsgrunnlag:** GDPR art. 6(1)(f) berettiget interesse i å håndtere forretningshenvendelser; eller art. 6(1)(b) når henvendelsen er ledd i inngåelse av avtale.  
**Lagringstid:** *[fylles inn — f.eks. henvendelser lagres i e-post inntil 24 måneder, deretter slettes med mindre kundeforhold eller rettslig plikt krever lengre lagring]*.  
**Mottakere:** meldinger sendes via vår kontakt-API / SMTP-leverandør til selskapets postkasser. *[Navngi SMTP-/driftsleverandør ved behov]*.

### 3.2 Tekniske logger

Driftsmiljøet kan automatisk behandle IP-adresse, brukeragent, forespørsels-URL/tidspunkt og lignende serverloggdata for sikkerhet, feilsøking og misbruksforebygging.

**Behandlingsgrunnlag:** art. 6(1)(f) berettiget interesse i sikker drift.  
**Lagringstid:** *[fylles inn — typisk 30–90 dager med mindre sikkerhetshendelser krever lengre]*.

### 3.3 Temavalg (ikke informasjonskapsel)

Nettstedet lagrer lys/mørk-modus i nettleserens **localStorage** (`theme`). Dette ligger på din enhet og sendes ikke til våre servere som del av vanlige sidevisninger. Se også [erklæring om informasjonskapsler](/no/informasjonskapsler/).

### 3.4 Skrifter og tredjepartsressurser

Nettstedet henter for tiden skrifter fra Google Fonts (`fonts.googleapis.com` / `fonts.gstatic.com`). Nettleseren din kan da kontakte Googles servere (IP-adresse og forespørselsdata). Vi bruker ikke Google Analytics eller annonsepiksler på dette nettstedet i dette utkastet.

**Merknad:** *[Anbefaler egenhostede fonter, eller dokumentert overførings-/samtykkeløsning, før lansering.]*

### 3.5 Hva vi ikke gjør (dagens nettsted)

Vi setter for tiden ikke egne HTTP-informasjonskapsler for analyse eller markedsføring, og vi selger ikke personopplysninger.

## 4. Overføring utenfor EØS

Dersom en leverandør (fonter, e-post, hosting) behandler data utenfor EØS, må overføring bygge på beslutning om tilstrekkelig beskyttelsesnivå eller egnede garantier (for eksempel standardkontrakter). *[List databehandlere og overføringsgrunnlag når kjent.]*

## 5. Dine rettigheter

Etter vilkårene i GDPR / personopplysningsloven kan du be om:

- innsyn
- retting
- sletting
- begrensning
- protest (inkl. mot behandling basert på berettiget interesse)
- dataportabilitet der det passer

Du kan klage til [Datatilsynet](https://www.datatilsynet.no).

For å utøve rettigheter, kontakt [post@mohntechnology.no](mailto:post@mohntechnology.no).

## 6. Sikkerhet

Vi bruker organisatoriske og tekniske tiltak tilpasset risikoen (tilgangsstyring til e-post, TLS for nettsted og API der det er satt opp, honeypot-felt i kontaktskjema mot enkle botter). Absolutt sikkerhet kan ikke garanteres.

## 7. Endringer
